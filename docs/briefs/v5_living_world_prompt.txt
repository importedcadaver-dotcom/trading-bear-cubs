# 4. CRITICAL UI/UX REDESIGN — REMOVE THE CLUTTER

The screenshots demonstrate serious information-density problems.

The game currently has too many simultaneously visible elements, with small typography and inconsistent fonts.

Research readable indie RPG interfaces, especially Stardew Valley, Animal Crossing, Recettear and Moonlighter.

## Visual requirements

- Use a cohesive pixel-art interface with two intentional typographic roles: decorative headings and readable body text.
- Eliminate inconsistent monospace/sans-serif combinations where they do not serve a deliberate hierarchy.
- Increase important labels, buttons and dialogue text.
- Add more color outside the world viewport: forest greens, honey gold, warm browns, berry red, muted blue and useful rarity accents.
- Avoid making every panel the same beige rectangle.
- Give individual features a distinct visual identity without overwhelming the screen.
- Prioritize the playable world.
- Make essential actions larger and easier to identify.
- Support UI scaling.
- Keep inventory easily accessible.
- Respect desktop and mobile layouts separately.

## Remove the permanent right-side dashboard

During ordinary exploration, the player should see the world, essential needs, context prompts and a compact inventory.

Bartering UI should appear only while bartering.

Mama's family UI should appear only during an appropriate family interaction.

Construction UI should appear when using the player's trading post, construction tools or a relevant workstation.

The full relationship encyclopedia, detailed market statistics, activity history and developer tools should not occupy permanent screen space.

Retain functionality, but organize it more appropriately.

## Menu audit

For every existing menu, decide whether it belongs in:

- Main HUD.
- Context interaction.
- Inventory.
- Journal.
- Pause menu.
- Trading-post management.
- Developer tools.
- A specialized location or workstation.

Remove redundant entry points and obsolete UI.

Do not silently delete gameplay features.

**Approach cub → Speak → Ask to barter → Examine offers → Negotiate → Accept/refuse/counteroffer → Visible exchange.**

- Sentimental attachment.

**Uncommon:** argument, unexpected gift, minor competition.
