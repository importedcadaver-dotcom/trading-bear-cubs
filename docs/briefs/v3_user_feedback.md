# v3 — User feedback prompting world expansion

- Whisperwood Clearing cannot be the entire visual world. Create a real **Mama's Den**, separate homes, a map, travel and distinct locations.
- Every player button/action needs meaningful gameplay feedback.
- Research and apply design principles for the game's social-life and trading genre.
- Other cubs should sometimes acquire **rare treasures**, make the player envious, and independently keep, hide or trade away prized items.
- Cubs can hide possessions and lie about them; persuasion, intimidation, threatening, blackmail, retaliation and snitching need meaningful autonomy and consequences.
- Being littermates must matter for the player and Pebble.
- Audit website styling, readability, information hierarchy and UI.
- Add a cheat/developer menu.
- Serious hunger can result in Mama intervening, or eventual starvation/death.
- Add multiple rare fictional vape labels/variants with usable effects.
- Clarify the complete item catalog and six rarity tiers/weights.
- Full action, event, and dialogue history; actual speech bubbles and conversation.
- Make the screenshot's game scene larger, inventory visible without scrolling, and never put the "YOU" label over the cub's eyes.
- Audit cross-system dependencies and address missing interaction effects.

This file captures the player's direction; it does not declare which v3 systems passed testing.
